# تحليل Tooth.exe

- `tooth-analysis.html`: افتح الملف في المتصفح لعرض التقرير العربي ومعاينة الشاشات المستخرجة.
- `tooth-simulator.html`: نموذج ويب تفاعلي؛ يدعم رسم الأسنان والأسلاك، السحب والدوران، الحفظ بصيغة JSON، والتراجع/الإعادة ومحاكاة توضيحية.
- `WEB_SIMULATOR.md`: حدود النموذج التفاعلي والوظائف المنفذة.
- `Tooth-analysis.zip`: حزمة التحليل والأدلة والبرامج المساعدة.
- `analysis-ar.md`: التقرير العربي بصيغة نصية.
- `preview.png`: صورة المعاينة.
- `forms.json` و`forms-summary.txt`: تعريفات الشاشات المستخرجة.
- `artifact.json` و`headers.json` و`pe-summary.json`: أدلة الفحص الساكن.

لم يتم تشغيل الملف التنفيذي. هذه معاينة للواجهات وليست محاكاة مكتملة لحركة الأسنان.

المحاكي التفاعلي ليس نسخة طبية مطابقة لحسابات `Tooth.exe`؛ لا تُستخدم قيم القوى أو الحركة فيه لاتخاذ قرار علاجي.

GitHub لا يدعم جعل مجلد واحد خاصاً داخل مستودع عام؛ الخصوصية تخص المستودع كله. وجود الملفات هنا لا يثبت أن المستودع Private.
