# تحليل Tooth.exe لإعادة بنائه كتطبيق ويب

تم الفحص الساكن داخل Linux Cloud دون تشغيل الملف أو تنفيذ تعليماته. استخدمت REA لفحص الأثر وGNU objdump للرأس، وpefile لاستخراج الموارد، وقارئاً لتعريفات Delphi DFM.

## الهوية المثبتة
- الحجم: 2,601,984 بايت، Windows PE32 x86، تطبيق رسومي أصلي وليس .NET (حجم CLI header يساوي صفر).
- SHA-256: `82e994b8f5a0e3be9cc4cae5ba40341dc1a8f8b55e1a27e2d8c28f82706e0068`.
- Delphi / VCL: موارد TPF0، عناصر TPaintBox/TPanel/TAction، ومسارات Embarcadero RAD Studio 10.0 داخل الملف. المسارات قرينة على سلسلة أدوات البناء وليست إثباتاً وحيداً لإصدار المترجم.
- شاشة About: Tooth، version 1.2، Orthodontic Tooth Simulator، Copyright © D.Halazonetis 1996-2024، Kifissia, Greece.
- بيانات إصدار Windows: FileVersion 1.2.1.0، ProductVersion 1.0.0.0؛ اختلافها عن About محفوظ كما هو.

## الشاشات الخمس المستخرجة
1. MainForm: مساحة رسم 2D بأحداث رسم وماوس، شريط أدوات وقوائم File/Edit/View/Ortho/Help، فتح وحفظ وطباعة، تكبير واختيار وتحريك ودوران، تشغيل/إيقاف، تراجع/إعادة، ونقطة مرجعية.
2. Tooth Info: تبويبا Tooth وPerio؛ طول الجذر التشريحي والوظيفي ومساحته، Angulation، dx/dy، Ankylosed، رسم استجابة الأنسجة ونتائج Force X/Y وMoment.
3. Wire: الطول، Force، Moment A/B، Angle Ratio، Burstone Class، اختيار مادة السلك ومقاسه.
4. Loop Options: General/View/Calculation؛ القوى والعزوم، أسنان أو أسلاك، شبكة 10/5/2 mm، Snap، مواضع رسم القوى، Auto Stop وحدود Force (gf) وMoment (gf.mm)، قيمتا الحد في تعريف الشاشة 1 و1.
5. About Tooth: التعريف والنسخة والمؤلف.

القوائم تعرض أرقام أسنان إضافية، لكن أصناف الأسنان الخاصة المستخرجة تؤكد 33،34،35،36،43،44،45،46 فقط. لا يمكن اعتبار كل رقم معروض في القائمة ميزة منفذة؛ بعض العناصر بلا معالج OnClick في تعريف الشاشة وقد توجد توصيلات وقت التشغيل لم نفحصها.

## النموذج الداخلي المستدل عليه من بيانات الأنواع
- TTooth: هندسة التاج والجذر، مركز المقاومة، Brackets، Ankylosed، rootLengthFunctional، rootAreaFunctional، stressTranslation، stressRotation؛ دوال Translate/Rotate/OrthoMove/SetAsOriginalPosition/ResetToOriginalPosition.
- TWireStraight: مادة ومقاس ونقطتا اتصال، MomentInertia، ModulusElasticity، Length، Force، MomentA/B، AngleRatio، BurstoneClass.
- TBracket/TAttachment: موضع وزاوية وارتباط بالسن والأسلاك.
- TForceMoment/TForceMomentV: تمثيل القوى والعزوم وتحويلها، بما فيه MomentAtPoint.
هذه أسماء وارتباطات مستخرجة، وليست برهاناً على معادلاتها أو دقة قيمها.

## ما يلزم لنسخة HTML
البرنامج يحتاج HTML وCSS للواجهات، وJavaScript للحالة والتفاعل والحسابات، وSVG أو Canvas للرسم. العرض الأصلي يعتمد على رسم برمجي في TPaintBox؛ لذلك استخراج النوافذ وحده لا يستعيد أشكال الأسنان المرسومة أو سلوك محرك الفيزياء.

البناء المقترح: نموذج Tooth/Wire/Bracket مستقل، طبقة رسم SVG ثنائية الأبعاد بوحدات mm، أدوات اختيار/تحريك/دوران وتكبير وشبكة، نوافذ خصائص، تاريخ undo/redo ومرجع initial state، حفظ JSON واستيراده وتصدير SVG/PNG وطباعة. محرك القوى وحركة الأسنان وحدة منفصلة مع اختبارات مرجعية قبل عرض نتائج كمية على أنها مطابقة.

الفتح والحفظ في الأصل يستخدمان مرشح Tooth files (*.txt). هذا يثبت الامتداد المقصود، ولا يثبت تنسيق البيانات؛ يلزم ملف حالة محفوظ من البرنامج لتحليل التوافق.

## حدود الفحص الحالي
- لم يتم تشغيل البرنامج أو تصوير شاشاته الفعلية؛ المعاينة المرفقة إعادة عرض لتعريفات التصميم المخزنة.
- لم تثبت المعادلات، ثوابت المواد، هندسة الأسنان، نموذج استجابة الأنسجة، قانون الحركة مع الزمن أو تصنيف Burstone المستخدم.
- Ghidra غير مثبت. يمكن إجراء فحص أعمق بـ Ghidra ومحرك Java المتوافق داخل Linux Cloud إذا احتجنا استعادة الحسابات؛ لا يلزم Mac لهذا الفحص. معايرة السلوك أمام البرنامج الأصلي تتطلب بيئة تنفيذ Windows مناسبة منفصلة، وليست متاحة ضمن هذا الفحص.
- لا يوجد تحويل تلقائي موثوق من EXE إلى HTML. بناء الواجهة ممكن؛ المطابقة الحسابية تحتاج أدلة إضافية.
- لم يكن هذا فحصاً أمنياً شاملاً، وعدم تشغيل الملف لا يثبت سلامته.

## المخرجات
`tooth-analysis.html`: تقرير عربي ومعاينة تفاعلية للواجهات والخصائص؛ اختيارات العرض والتبويبات تعمل، أما أزرار البرنامج الأصلية فغير مفعلة.
`forms.json`: جميع النماذج المحللة، شجرة العناصر، المواقع، النصوص، أسماء الأحداث. القيم الثنائية الكبيرة موصوفة بحجمها وبادئتها فقط؛ الموارد الخام محفوظة منفصلة في مجلد التحليل.
`artifact.json` و`headers.json`: أدلة REA مع بصمة الملف ونتائج الفحص.

لزيادة دقة إعادة البناء: ملفات TXT المحفوظة والأمثلة قبل/بعد الحركة ولقطات الشاشات من المصدر إن كانت متاحة تساعد على استعادة الرسم والتحقق من الحسابات. لا تعتمد الحسابات المعاد بناؤها في قرارات علاجية قبل التحقق من صحتها.
