# Tooth Web Simulator

افتح `tooth-simulator.html` مباشرة في المتصفح. لا يحتاج خادماً أو اتصالاً بالإنترنت.

النسخة الحالية تعمل كـ MVP تفاعلي:

- إضافة الأسنان 33 إلى 46، تحديدها، سحبها وتدويرها.
- إضافة سلك، شبكة، تكبير، عرض متجهات قوة توضيحية.
- تعديل خصائص السن، تراجع/إعادة، حفظ وضع مرجعي والعودة إليه.
- حفظ وفتح ملفات JSON الخاصة بهذه النسخة.
- حركة تجريبية يمكن تشغيلها وإيقافها، مع دعم Auto Stop.

المحرّك الحسابي هنا ليس إعادة إنتاج لمعادلات Tooth.exe ولا يجوز استخدامه لاتخاذ قرار علاجي. مطابقة المنطق الأصلي تحتاج تحليل إضافي للكود أو ملفات حالات ونتائج مرجعية من البرنامج الأصلي.
